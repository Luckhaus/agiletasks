# Agiletasks
Sistema de gerenciamento de tarefas com prioridades usando metodologia ágil, pela plataforma Miro

Descrição:
O AgileTasks é um sistema simples de gerenciamento de tarefas desenvolvido em Python, com foco na aplicação de metodologias ágeis e boas práticas de Engenharia de Software utilizando o GitHub.

 Objetivo:
Permitir o controle de tarefas de forma eficiente, incluindo criação, edição, remoção e definição de prioridades, simulando um ambiente real de desenvolvimento ágil.

 Funcionalidades:
- Criar tarefas
- Listar tarefas
- Editar tarefas
- Deletar tarefas
- Definir prioridade (baixa, média, alta)

 Tecnologias utilizadas:
- Python
- GitHub
- GitHub Actions (Integração Contínua)
- PyTest (testes automatizados)

 Metodologia Ágil:
Foi utilizada a metodologia Kanban para organização do projeto, com as seguintes colunas:
- To Do (A Fazer)
- In Progress (Em Progresso)
- Done (Concluído)

 Como executar o projeto

```bash
# Clone o repositório
git clone https://github.com/Luckhaus/agiletasks.git

# Acesse a pasta
cd agiletasks

# Execute o sistema
python src/main.py
